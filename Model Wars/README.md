# Model Wars

Machine learning competition project with Marvel Avengers Doomsday dataset.

## Files
- `avengers_doomsday.ipynb`: Primary exploration, model training, and submission generation notebook.
- `feature_map.csv`: Feature mapping definition.
- `label_map.csv`: Classification labels mapping.
- `sample_submission.csv`: Benchmark submission format.
- `test.csv`: Evaluation dataset (~48.5 MB, tracked in Git).
- `train.csv`: Training dataset (~220.6 MB).
